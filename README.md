## Overview

Valhalla Shimmer creates the classic pitch-shifted reverb shimmer sound, blending pitch octave feedback into infinite reverb trails for ambient, cinematic, and experimental music.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Valhalla Shimmer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Pitch Shift** | Up to two independently tunable pitch shift amounts per reverb trail |
| **Infinite Mode** | Sustain mode for infinite, evolving pitch-shifted reverb drones |
| **Dense Algorithm** | High diffusion density for smooth, choir-like shimmer tails |
| **Mix Control** | Wet/dry blend enables subtle or overwhelming shimmer application |
